# Praktisch Ausprobiert – Website-Entwurf

Dieser Entwurf ist als erste öffentliche Website für das Affiliate-Projekt vorbereitet. Die Startseite eröffnet das Projekt mit 3D-Druck und lässt später Platz für Alltag, Hunde, Fotografie und Stil.

Vor dem Veröffentlichen müssen noch ergänzt werden:

- die endgültige Webadresse und eine Erreichbarkeit für Kontaktanfragen;
- ein rechtssicheres Impressum und Datenschutzhinweise mit den echten Angaben der Betreiberin oder des Betreibers;
- mindestens ein bis drei veröffentlichungsreife Artikel;
- eine eindeutige Kennzeichnung, sobald Affiliate-Links eingefügt werden.

Die Dateien `index.html` und `style.css` bilden die Website. Sie können anschließend bei einem geeigneten Hosting-Anbieter veröffentlicht werden.
